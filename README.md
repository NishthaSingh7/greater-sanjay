# greater-sanjay

## Project name
greater-sanjay

## Year
2026

## Purpose
Greater Sanjay — universal screen-based macOS control layer, built at Cursor Buildathon

## Features
- System-level control across apps via screenshot observation and UI actions
- Local vision and reasoning with Ollama (on-device)
- Structured click/type/shortcut execution with post-action screenshot verification
- Fast-path playbooks for common flows (Spotlight, Spotify, Chrome, YouTube, and more)
- Electron desktop shell with TypeScript main and renderer processes
- Electron + TypeScript

## Tech Stack used
- Electron
- TypeScript
- Zod
